## ✨ Features

* **3D Spatial Sketchbook Arena:** Slither inside an open graph-paper arena with charcoal bounding lines and floating 3D doodles (steaming coffee mugs, golden stars, and floating pulsating orange hearts 🧡).
* **Full WebXR Controller & Haptic Support:** Native thumbstick movement on Meta Quest controllers with tactile vibration feedback on every bite.
* **3D 6-Axis Movement:** Guide the snake horizontally across the grid (`X`/`Z`) and climb into the air or dive down (`Y` elevation).
* **Zero Install Required:** Runs directly in Meta Quest Browser, Apple Vision Pro Safari, and modern desktop/mobile browsers.
* **Built-in Lo-Fi Soundtrack:** Web Audio synthesizer streaming 3 chill tracks (*Blue Lightning ⚡*, *Afterglow 🌅*, *Run Away 🏃‍♀️*).

## 🕹️ Controls

| Control | Meta Quest / VR | Desktop / Keyboard |
|---|---|---|
| **Turn Left / Right** | Left Thumbstick (X) | `A` / `D` or `Left` / `Right` |
| **Move Depth** | Left Thumbstick (Z) | `W` / `S` or `Up` / `Down` |
| **Climb UP (Y Axis)** | Right Thumbstick (Up) | `E` |
| **Dive DOWN (Y Axis)** | Right Thumbstick (Down) | `Q` |
| **Orbit Camera** | Head Tracking | Click & Drag Mouse |
